# 城市镜像写作法

> 版本：v4.31（2026-08-15）。每次修订更新本行，变更明细见 `CHANGELOG.md`。
> 方法论来源：2026 年 7 月「以长鑫科技上市为镜、对照山西国资」一文的完整实战流程，并经多轮修订。
> 核心思想：热点的价值不是蹭流量，是当镜子——借外地的一个具体事件，照出本地的历程、问题与手里的牌。对比落点永远放在「机制差异」，而不是「城市高下」。镜像不是预先判定的赛道，而是「此地 vs 别处」型落差成立时的自然写法；对弱存在感地区，「此事与本地无关——或时机未到、先养起来」也是合格输出。

## 读懂本 skill：约束三层制

本 skill 的规则分三层，效力不同，不要一视同仁：

- **红线（必守，无例外）**：来源纪律、核实与锁清单、可写事实清单、口径与暂缺、双层合规、情绪越位、单引擎检查、落差自检（当事人测试）、试讲纪律（必须难看、强制举证、不作成稿底稿）、调研底稿落盘、禁止用修辞补救上游问题；
- **默认（照跑，用户可一句话关掉）**：立意五步流程、篇幅分档、双审、标题参考、HTML 交付；
- **工具（帮你找，不替你写，找到即退役）**：骨架五问第 4 问（阶段三提炼辅助＋阶段四单点复检；第 1/2/3/5 问经台账两篇未出力已删）、样式库（阶段四表层样式）。

规则的去留由实战审计决定（见末节），不由偏好决定。

## 全流程总览

```
① 概念界定与选题评估（否决 → 客体 → 受众 → 现在写 / 养 / 丢）
② 广撒网（双图）→ ③ 立意决策（五步）→ ④ 结构（试讲定线→五问复检→选样式→按主线分节→单引擎）
→ ⑤ 沿线深挖 → ⑥ 核实锁清单 → ⑦ 叙事成稿（写 → 扫）
→ ⑧ 双审（合规+主观性）→ ⑨ 交付（MD 定稿 → HTML 预排版）
（快评走轻量路径，见阶段一体量判断；
  改稿按「改稿复检」的分级规则回到 ⑧ 重跑）
```

每个阶段都有明确的产出物和质检标准，不要跳步。贯穿全程的五条骨干规则：

- **调研三轮**：②广撒网 → ⑤沿线深挖 → ⑥核实锁清单。三轮笔记全程继承——登记过的事实与来源，任何一轮不重复检索，上一轮作业是下一轮底稿；
- **用户拍板点**：①选题（多题待筛时；单题直接展示回避项后继续）、③立意、④样式与修辞主线（④一次呈报确认，不分两问）。不要替用户决定；
- **⑧双审**在发布前完成，两审缺一不可；
- **按需读取参考文件**（不要为保险一次全加载，只读当前确实命中的）：
  - `references/structure.md`——④结构的七步操作细则。**进入④时读；快评跳过④⑤，不必读**；
  - `references/review.md`——⑦第二轮扫查／⑧双审／改稿复检／质检清单。**初稿完成后才读，动笔前不加载**（写作时若禁词表在上下文里，会照顾显性检查项而牺牲隐性叙事）；
  - `references/delivery.md`——⑨交付：双版本、配图、预排版、草稿箱推送。**正文定稿且双审通过后才读**；
  - `references/draft-template.md`——①开始调研时读，照模板留好底稿空节；
  - `references/pattern-samples.md`——④选样式遇到边界或易混淆情形时读；
  - `references/research-agent-prompt.md`——②⑤ 派子 Agent 前读；
  - `references/narrative-principles-evidence.md`——⑦成稿需要样文佐证时读；
  - 冲突时以 SKILL.md 的红线为准，参考文件只细化「怎么做」，不改变「什么算过」；
- **回扫**：每次新选题进入阶段一，先扫一遍养题库；
- **调研底稿落盘（红线）**：每轮产出都追加写进工作目录下的 `文章名_调研底稿.md`（普通 md 即可）——**登记在文件里，不只登记在上下文里**。要落盘的有七样：打分卡、双图、立意产出清单、各拍板点的用户选择记录、线索对照表、深挖笔记、可写事实清单。章节骨架见 `references/draft-template.md`，照模板留好空节，防漏（判例：台账第 2 篇）。（思想借自横纵分析法的研究底稿落盘，格式从简。）

### 关键术语一句话（只作地图，完整定义在各自首次出现处）

- **落差**：两组对不上的事实、两边都有出处——文章的燃料（①）；
- **打分卡**：选题评估的结构化产出：载体/落差/体量/时效/在地/回避项（①）；
- **双图**：认知地形图（别人写过什么）＋素材地图（事实本身有什么）（②）；
- **认知任务**：论点落在认知五段（描述/解释/检验/预测/规范）的哪一段——决定论证结构与结尾方式（③定名）；
- **主线**：读者跟着什么走：时间/空间/对象/流转/追问（④试讲定出）；**修辞主线**：主线的比喻名（如"三张账单"）；
- **样式**：已验证的"主线×素材形态"组合，甲乙丙丁四种（④）；
- **可写事实清单**：⑥锁清单的产出——成稿只准用清单内的事实；
- **台账**：`CHANGELOG.md` 里的逐篇实战审计记录，规则去留的证据来源。

## 阶段一：概念界定与选题评估（任何选题先过这一关）

### 第一步：概念界定（先于一切核查与评估）

**目的**：先与用户对表，确保后面聊的是同一个东西。同名不同物、相近概念、政策口径里的正式定义，都是高发雷区（实战教训：共享单车 / 共享电单车 / 公共自行车是三种东西，混用会让后续调研全部跑偏）。

**什么时候界定**（双向检验，任一命中即做，都不命中一句话带过）：

- 对内：这个词不界定，调研会不会搜错对象？
- 对外：模拟目标读者（本地市民、非专业）听到它的反应——会反问"你说的是哪个"（同名不同物），或理解成相近概念（把"抬板住宅"当"第四代住宅"），都要界定；"美特好"这种全城有默契的词不用。

**怎么做**：

1. 有歧义就向用户出选择题（"你指的是山西文旅这个产业，还是山西文旅集团这家公司？"），不替用户猜，也不逢词必问；
2. 用户选定后给准确定义：优先官方口径（政策文件、统计定义），没有则给工作定义并标注。

**产出与去向**：定义写进调研任务书，所有子 Agent 共用同一套概念；读者不熟的词，正文里必须给读者版解释。

**边界与提问纪律**：本步只解决"这个词指什么"，不谈文章写什么、从哪写（那是③立意决策的活）。

**整个阶段一，允许向用户提的只有一类问题：概念歧义选择题。**要问别的之前先自答一句：这个问题的答案，能不能从打分卡或②的双图推出来？能——自己推，不问。用户已经答过、或已经说"按流程走"的，同一问题不得重问。

（判例：2026-08-07 实跑观察，见台账「抢跑提问」条——agent 在①就问用户"这篇想追问的核心方向是什么"并列出三个立意方向选项，用户答"还没定，先跑选题评估"后又重问一次。方向是③由「落差 × 空白」推出的产物；在①问，用户手上还没有双图，答什么都是拍脑袋，后续调研必然围着一个未经检验的方向跑偏。）

### 第二步：选题评估（否决 → 客体 → 受众 → 三分制）

**目的**：回答三件事——写不写、养还是丢、现在写走哪条路径。评估依据来自三方：客体（对象有货吗）、受众（读者此刻需要吗）、自我。其中「自我」不作为闸门：独家素材由用户主动提供，不主动问、不停机（防平庸由落差关与认知地形图兜住；全流程唯一的主动素材请求点是⑥的一手素材愿望清单）。三方之外加一票否决（负面清单）。

裸话题（用户未带热点）先盘点手头已有的钩子作为评估对象，**盘 3-5 个，每个一行：钩子｜来源｜为什么现在提**（来源三类：养题库触发项、既往调研底稿的钩子候选、近期本地节点）。只盘不选——盘点是为了让用户有得挑，不是在这一步定选题；盘不满 3 个说明手头确实没料，如实说，不硬凑。

总原则：检验成本从低到高，任一关不过即停。

#### 第一关：负面清单（两层生效）

- **概念级**（硬否决，极窄）：整个议题任何切口都不能碰的才列（如涉现任领导人、未经官方发布的重大事件细节）。命中 → 彻底丢。
- **角度级**：概念可写、部分切口不可写，逐切口过滤，留下能写的（例：国企改革可写机制/产业/市场，不写具体人事与责任归属；美特好可写重整机制与行业洗牌，不煽动储值卡维权、不点名个人责任）。角度级拦"切口"，与阶段八第一审合规拦"表述"，两道不重复。

#### 第二关：客体维度——对象本身有货吗

1. **载体**：这个话题能不能落到具体的东西上——一栋楼、一家公司、一笔钱、一份文件、一群人。评分依据：能列出 ≥2 个有名有姓的载体＝过；只能说出抽象词＝不过。没有载体的概念只能写成评论，而评论谁都能写。
2. **落差**：载体身上有没有对不上的地方——说的 vs 做的、账面 vs 实际、此地 vs 别处、现在 vs 当初承诺（对不上的那道口子，就是文章的燃料）。评分依据：四类落差找到 ≥1 条、且两边都有出处＝过；只有一边有出处的，是情绪不是落差＝不过。没有落差就会写成通稿或企业介绍。
   **防滥用自检（红线，必过）**：这个落差，如果由当事人来解释，他有没有一个说得通的版本？如果有，而稿子里没写进去，那就不是在报道落差，而是在生产落差（把正常进度差写成失败、把规划口径写成欺骗，都是生产落差）。测试发现的版本以「反对者版本」记入打分卡，成稿必须写进正文（见阶段七）。
3. **父子话题**（体量匹配，双向检验）：
   - **太大 → 大题小做**：切出 ≥1 个自带载体和落差的子话题；切不出＝过大则空，不过；
   - **太小 → 小题大做**：小题能否挂上至少一层更大的主题（行业变迁/城市命运/时代情绪）？挂不上＝撑不起深度文，只配快评/解读路径或弃。

#### 第三关：受众维度——读者此刻需要吗

1. **时效**（时间距离）：节点距今 ≤30 天＝新鲜；30–180 天＝温（需新由头）；>180 天＝旧（只能当素材，除非周年/新节点刷新）。**新由头**（防卡死也防滥用）：近 30 天内发生的、可直接用作文章开篇的具体事件（公告/开业/表决/数据发布，有名有姓有日期）；「仍在进行中」这类模糊状态不算由头。
2. **在地**（利害距离）：直接影响本地读者（钱包/房子/出行/孩子）＝强；间接影响（城市产业/形象）＝中；仅供谈资＝弱。检验语：本地老百姓会不会问"这跟我有啥关系"。
   评分依据：时效新鲜或在地强＝过；时效旧且在地弱＝不过。

#### 执行分工

- **agent 筛**：第一~三关逐题输出打分卡——【载体清单】【落差：类型+两边来源｜当事人解释测试：过/不过+反对者版本】【父子：体量判断（深度文/快评）】【时效：档位】【在地：档位】【否决：命中/未命中+角度级回避项】【结论：客观可写/不可写＋一句理由】；
- **用户拍板**：用户带着明确选题来的（单题），打分卡产出后展示回避项与反对者版本，三关无否决即继续——回避项随打分卡锁定，不再单独问"写不写"。多题待筛或开放式提问时，从"客观可写"清单中选定。

#### 产出：三分制

- **现在写**（例外，少数）：三关全过 → 按体量分路径：
  - **深度文**：小题挂得上大主题，本地节点自足或带同重量级外地对照（如长鑫×山西国资）→ 走阶段二~九完整流程；
  - **快评**：体量只撑得起观点输出 → 轻流程（跳过④结构与⑤深挖）：广撒网简版 → 立意简版（拉简版交叉表，见阶段三）→ 核实简版（关键数字逐条过口径，产出迷你可写事实清单——快评也不许用清单外的事实）→ 成稿（快评属性，第二轮并入双审）→ 双审 → 交付；
  - 镜像/主场/解读不再是评估时判定的赛道——带不带外地对照看打分卡的落差类型，形态在立意拍板与样式选择时自然呈现。
- **先养起来**（默认，占大头）：客体或受众缺一环，但能写出可核查的触发条件。写不出触发条件的不许养。
- **彻底丢**：硬否决命中，或客体受众双空且无变化预期。对弱存在感地区，承认"此事与本地无关"是城市号的自律。丢也留痕（`养题库/_已丢.md`，一行一条：日期｜话题｜原因），防重复评估。

#### "养"档落库格式

位置：当前写作目录下 `养题库/话题名.md`。

**下例为格式示例，内容纯属虚构——回扫只认 `养题库/` 目录下的实体文件，文档示例不是档案**（判例：台账第 2 篇把旧版示例〔话题恰为真实选题〕当成真实养档，凭空生成了"回扫触发"记录）。

```
---
话题: 雾岭市低空通勤航线（虚构示例；概念界定后的一句话口径）
状态: 养                # 养 / 现在写 / 丢
建档: 2026-08-05
最近评估: 2026-08-05
缺口: 客体缺载体（本地无落地项目）；在地性中偏弱
触发条件:
  - 事件: 本地出现航线试点获批、空域开放公告或运营商官宣
  - 事件: 省级出台低空基础设施补贴政策
  - 时间: 2026-11-05    # 季度复查，最长一个季度
---
## 证据时间序列
（一行一条，新的追加在末尾：日期｜证据｜来源 URL｜指向哪个缺口/触发条件）
- 2026-08-05｜邻省 A 市开通同类航线，政策扩散中｜URL｜邻近触发条件②
## 备选论点库
（立意五步的落选者：论点（一句陈述）｜位置（维度×认知段）｜三测结果（证伪条件/反对者理由/可证判定）｜落选原因——调研成本已付，同话题新节点时直接取用）
## 评估史
- 2026-08-05 判养：载体不过（本地无载体），在地中。
```

**回扫机制**：每次新选题进入本步骤，先扫一遍养题库——触发条件满足的取出重评；时间型到期的快速重扫新闻再定。触发条件写法：事件型必须可核查（"出现 XX 公告/公示/土拍"，不写"有进展"）；时间型最长一个季度。

**边界**：本步只做选题级核查（落差两边有出处、关键口径初核即可）；全部进文数字的口径终核在阶段六完成。

## 阶段二：广撒网（轮一）

定结构之前，先看清两张地图：别人说过什么，事情本身有什么。宽而浅，**固定 3 个子 Agent，与下面三轴一一对应**（纵向/横向/交汇各一个），单 Agent 产出 ≤1500 字。素材特别厚时可加第 4 个，但须在任务书里写明它补的是哪一轴的哪个缺口——不写明的第 4 个不许开。

**单人执行降级路径**（宿主不支持派子 Agent，或用户要求不派时）：不派 Agent 不等于跳过三轴。**主 Agent 依次跑完三轴，每轴单独成节记录，轴与轴之间不混着搜**——三轴的价值在于视角分工，混着搜会退化成一轮泛搜。搜索预算改为**总计 ≤12 次**（原 3×5=15 的八折，因单人无并行重复损耗），单次深入提取仍 ≤3 个页面。产出格式与派 Agent 时完全一致（三轴笔记＋双图），底稿中注明"本轮为单人执行"。**一批搜索，两种归档——不是两轮搜索。**

**两种归档方式**：

- **认知五段（话语地图）**：切的是别人的报道。人认知一件事分五段——**描述**（这是什么）、**解释**（为什么是现在、为什么这样）、**检验**（真的是这样吗）、**预测**（接下来会怎样）、**规范**（应该怎么办）。媒体对一个话题的书写就分布在这五段里；要找出哪段拥挤、哪段空白、哪段有分歧。
- **六维（素材地图）**：切的是事实本身——这件事在人（人物/使用者）、财（账本/资金）、物（设施/产品）、空间（区位/格局）、时间（节点/周期）、制度（政策/规则）上分别有什么。每条必须是有出处的事实，不是类目词；无料的维度直接略过，不硬凑。

打分卡不指挥本轮——它服务评估结论与深挖复核。

**扫描分工（三轴）**：三轴借自数字生命卡兹克的横纵分析法（纵向追时间深度、横向追同期广度、交汇产判断），此处仅作快速扫描的分工，不做完整研究报告。

- **纵向**：话题自身的生命历程（本地与外地双边）；
- **横向**：当下截面的同类/竞品坐标；
- **交汇**：格局与政策脉络、本地手里的牌。

**子 Agent 返回格式**：按子任务分节的笔记（每条事实带来源）+ 每条主要发现打认知段标签（【描述】/【解释】/【检验】/【预测】/【规范】）+ 扫描轴内主流判断记录（一句话+来源，标注趋同/分歧）+ **素材归档（六维分桶，每条带出处，无料的维度略过）** + 钩子候选（至少 1 个）+ 一句话盘点"本轴内哪个认知段料最多、哪个空白"。

**产出（主 Agent 组装）：双图**——

1. **「认知地形图」（话语地图）**：五段 × 密度（多/少/空白）× 趋同度（趋同/有分歧）× 代表作链接，外加钩子候选清单。判断标准：料厚且趋同＝别去（挤进去是第 101 篇通稿）；料薄、空白或有分歧＝发力点候选。趋同/分歧是子 Agent 的一线判断，组装时抽查出处。
2. **「素材地图」（事实归档）**：人/财/物/空间/时间/制度六维，每维下列出有出处的事实与载体——写文章能用的切入点基本都在这六个筐里。

注意：本轮不深挖，任何方向都不展开。它的产出是地图，不是建材。产出即落盘（见总览·调研底稿落盘）。

**来源策略（本轮与⑤不同）**：画地图用覆盖面宽的源，不追一手原文：

- 行业媒体综述 / 数据聚合平台 > 权威媒体单篇报道 > 官方文件原文；
- 聚合源引用的数字按原文记录即可，口径终核留给⑥——②只管发现，不管终核；
- 本条覆盖子 Agent 模板中"一手来源优先"的默认优先级。

**搜索预算**：每个子 Agent ≤5 次搜索（WebSearch），每次搜索深入提取 ≤3 个页面（FetchURL）。预算是上限；搜完仍有空白的，标「暂缺」留给⑤，不加搜。

**数据系列完整登记（红线，为⑨配图预留建材）**：搜到**时间序列或多对象同指标**数据时（社零、GDP、人口、销售额、房价等），**登记完整序列，不只登记正文可能用到的那几个点**。正文只会截取其中两三个点，但⑨出图需要完整序列——不完整就得回头重搜，成本远高于登记时顺手多记几行（实战教训：太原社零②只记了正文要用的三年，⑨出图时重搜 6 次仍未补齐）。

登记格式（写进调研底稿「数据系列」节）：

```
指标: 太原社会消费品零售总额
口径: 全市｜当年价｜含餐饮
序列: 2021=1873.90(+13.2%) | 2022=1761.40(-6.0%) | 2023=1912.88(+8.6%) | 2024=1946.92(+1.8%) | 2025=2365.53(+4.7%)
出处: 太原市统计局《2025年国民经济和社会发展统计公报》图4 + URL   ← 同一份公报的连续序列，内部同口径
备注: 2019 年另有两个值——2019年公报 1952.81，2020年公报图5 已修订为 1769.01，跨公报取值以新版为准
```

**登记三项纪律**：①**注明出自哪一份公报**——同一份内部必然同口径，跨公报拼接才需担心修订；②**同比增速一并记**，但只作参考，**不得用来反推绝对值**（增速可比口径、绝对值当期口径）；③发现同一年份在新旧公报里数值不同的，**两个值都记下并注明版本**。

**来源登记的两档要求（防「待补URL」堆积）**：②允许先记聚合源摘要，但**每条事实必须当场标出「源级」**——`一手`（官方原文/年报/评级报告，须带 URL）／`二手`（权威媒体原创，须带 URL）／`转述`（聚合摘要，可暂记媒体名＋日期，URL 标〔待补〕）。
**「待补」的补齐时点是⑥，不是⑤，也不许拖到成稿**：⑥核实锁清单时，凡要进正文的事实，`转述`级必须升到 `二手` 或 `一手` 并补齐 URL；升不上去的，要么不进正文，要么在口径说明里写明"来源为媒体转述，原始出处暂缺"。**清单里带〔待补〕的事实不得进入可写事实清单**——这是⑥的准入条件，不是建议。

**完成标准**：素材地图六维每维 ≥1 条事实或标「本维无料」；认知地形图五段每段标出密度与趋同度；遇到的时间序列均已完整登记；每条事实均已标源级。地图允许空格，但空格必须是标出来的，不是漏掉的。

## 阶段三：立意决策（拉交叉表 → 换问法 → 提炼 → 三测 → 产出）

立意决定"说什么"，样式决定"怎么说"，立意在样式之前。立意最常见的失败是停在过大的话题上；而大多数选题的失败不是没材料，是拿材料问了一个别人已经问过的问题。下面五步是线性流程；快评走简版（只拉主维度×五段的小表）。

### 一、拉交叉表

把广撒网双图里的材料，摊成一张交叉表：**素材六维（人/财/物/空间/时间/制度）× 认知五段（描述/解释/检验/预测/规范）**。每格填三样：该维在该段有几条材料、外部媒体在该段的密度、①评估的落差落在哪格（打星）。

四种格子四种命运：

- **有料 + 外部空 → 主推候选**（真正的"落差 × 空白"）；
- **有料 + 外部厚 → 降级为论据，但先做换问法尝试**；
- **无料 + 外部空 → 待挖清单，交阶段五去挖**——全表最值钱的格子：空段不是没东西可写，是还没人去拿；
- **无料 + 外部厚 → 忽略。**

落差不是第三根轴，它长在第一根轴上：同一个格子里，一堆事实只是素材；两组对不上的数、两边都有出处、且过了当事人测试，才算落差（打星）。**落差可跨格**（如财×制度对撞产生落差），星标注记跨及的两格即可，不强行归入一格。表是透镜，不是表格作业——大部分格子一眼略过，不许把 30 格当 KPI 填。

### 二、换问法（唯一的调节动作）

对每一条"有料但落在外部厚"的材料，沿行横移一次：同一批事实，换一个认知任务来问，能不能挪到空格？

例："T3 延期两年"在描述段已写烂。横移：挪到解释段——谁的决策导致延期、卡在哪个环节？挪到检验段——官方给的延期理由和公开的施工节点对得上吗？挪到预测段——按这个节奏后续还会不会延？同一批事实，四种论点，拥挤度完全不同。

边界两条：**换问法只换问题，不换事实**（挪到检验段最易把正常事实曲解成疑点，那是生产落差的流水线）；挪不动就留在原段做论据，不硬挪。换问法之后的新论点照常过三测。

过时素材（旧于 180 天且无新节点）的两条出路也在此裁定：降级为背景论据，或反转进检验段（"迟到者跑得快"→"迟到者真的跑得快吗"——这正是横移的一种）；所有论据标注年份，交⑤登记。

### 三、提炼（每格出一句，不是一段）

对主推候选格，各写一句论点。硬性要求：必须是陈述句，必须带方向。

- ❌ "太原算力产业的发展情况"（名词短语，不是判断）
- ❌ "太原算力面临机遇与挑战"（有句子形式，无方向）
- ✅ "太原算力项目的实际上架率，远低于对外宣传的机架规模"

判定方法：把这句话反过来说，能不能成立？反过来说不通、或者反过来说也没人反对，都不是论点。

**辅助工具：骨架五问第 4 问**（借自横纵分析法的交汇五问，此处只做提炼论点的提问工具，问出论点即退役）：**当初的"好决策"有没有变成今天的包袱？**——最常产出解释型论点（实战例：太原两轮文用它挖出"财政包办"的包袱；太原出租车文挖出"一次性整体置换"的周期包袱；澐玺文印证"引恒大"之困）。

降级记录：原五问中的第 1/2/3/5 问（历史塑造当下 / 主体纵向对比 / 优势根源 / 未来三剧本）经台账第 1、2 篇连续未出力，2026-08-07 按三层制删除（工具层两篇未出力→删除），原文存 CHANGELOG v2.3。

### 四、三测淘汰

每句论点过三测：

- **可证伪**——写得出"如果看到 X，这个判断就不成立"的那个 X。写不出 X 的，不是判断；
- **有反对者**——说得出谁会反对、理由是什么；
- **可证**——公开材料够／不够／不确定，由 agent 判；私域能不能补上，由用户判（agent 不掌握用户手上有什么，不替用户编）。

**"不够"不等于淘汰，先走降级阶梯**：原论点证不了 → 降一格，换一个能证的邻近判断（如"三处口径对不上"）→ 还证不了，再降一格（"相关数据截至 X 日公开渠道未见披露"）。最后这一格本身也是可写的事实，但只能写"未见披露"，不能暗示隐瞒。大多数好论点都是在阶梯上找到位置的，不是一次就立住的。

每降一格加一问：**降级后的论点，还在回答打分卡里的那条落差吗，还是只在回答"数据乱"？**答后者就换维重选，别再往下降——一路滑到底，产出的是口径校对报告，不是判断。

**三测之后必须剩下不止一个**。两个幸存者还得有实质差异，不是一个论点的两件马甲。没有比较就没有选择。

**只剩一个时不许直接放行，回第一步补格**（通常是前面罗列不够，或三测执行过严）：重扫交叉表里未提炼过的候选格，补提论点再过三测。补完仍只有一个的，在立意产出清单里记一行「已复查交叉表，确为唯一幸存」再继续——**是"复查后放行"，不是"只剩一个也能走"**。

### 五、产出（拍板时手上的清单，即「立意产出清单」，随调研底稿落盘）

- **论点**：一句带方向的陈述句；
- **位置**：维度 × 认知段；
- **认知任务**：即该位置的认知段（描述/解释/检验/预测/规范）——④的定线匹配与论证结构、⑦的结尾分档都以此为准，此处显式定名，下游不再换叫法；
- **证伪条件**：如果看到 X，不成立；
- **反对者理由**：与阶段一当事人测试同一字段，成稿必须进稿；
- **可证判定**：公开材料 够/不够/不确定 + 需要哪些私域补充（私域由用户判，纪律同阶段一：只标注、不主动问、不停机）；
- **落选者**：其余通过三测的论点，两种去向——本次搭配（引子/收尾，搭配不改变单引擎约束），或存入养题库「备选论点库」（论点/位置/三测结果/落选原因），同话题新节点时直接取用；
- **待挖清单**：第三类格子，交阶段五任务书。

全部摆齐后由用户拍板（选定主立意与搭配）。

### 拍板前三道检查

1. **问题定性**：一句话说清本文追问的对象——"不是质疑 X（如必要性），而是追问 Y（规模/路径/代价）"。定性不同，全文的合规风险等级和读者情绪完全不同。定性随立意产出清单落盘，⑧第一审据此复查全文有没有漂移。
2. **对照辨性质**：论点里的对照必须是性质对照——数字量级差不等于性质差异（实战例：超投 127 辆一票否决与清退 1.5 万辆，性质都是一刀切；真正的分野是"约束"与"禁止"）。
3. **贴身检验**：这个论点如果成立，本地读者的哪个决定、哪种情绪会因此不同？答不出的降为论据，不上拍板清单——三测筛的是"是不是判断"，这一问筛的是"是不是值得写的判断"（在地性在①判的是话题，不是论点，此处补上论点级的那一关）。

## 阶段四：结构（试讲定线 → 五问复检 → 选样式 → 判框架先行 → 按主线分节 → 定修辞主线 → 过单引擎）

核心原则：**主线在前，样式在后**。主线由证据分布客观推出，样式随之收敛。

**读取 `references/structure.md` 后按其执行**（七步操作细则全在该文件）。**快评路径跳过④⑤，不必读**。

七步与各步的闸：

1. **五线试讲（定线）**——红线：试讲稿必须难看、强制举证（每条线至少一处「此处无料」）、**试讲稿不作成稿底稿，定线后作废**；产出线索对照表与「断在哪」清单；
2. **五问复检（单点）**——不一致时不自动改论点，记录后提请用户判断；
3. **选样式**——两轴（主线×素材形态）＋四个具名样式（甲乙丙丁）＋快评属性；结果唯一直接采用，多候选或需临时组合才请用户选；
4. **判框架先行**——规则触发：认知任务＝检验或规范则必需；
5. **按主线分节**——每节标五样：功能／挂主线哪一环／已配弹药／待挖目标与预算档／概算字数；
6. **定修辞主线**——与样式一并呈报，用户一次确认（④唯一拍板点）；
7. **过单引擎（红线）**——每节一句话答出「如何推进主线」，答不上当场删，判不准用删节测试。
### 接口

- **入口（③→④）**：论点、认知任务、证伪条件、可证判定、待挖清单；
- **出口（④→⑤）**：定线结果、五问复检记录、「断在哪」清单（含待挖清单残项，即深挖任务书）、样式、节次骨架（每节五样）、修辞主线（当前版，⑤挖到更好钩子时对比）、证伪条件（作为深挖靶子）；
- **回退**：五线试讲全部不足 3 块硬材料 → 回阶段三降级或换维；五问复检不一致且用户判定论点需改 → 回阶段三。

## 阶段五：沿线深挖（轮二）

沿阶段四交来的节次骨架与「断在哪」清单深挖，其余方向不碰。

**继承说明**：本阶段的来源纪律继承自横纵分析法的**纪律层**（来源优先级 / 暂缺不编造 / 底稿落盘），不继承其框架层——充分性自检、篇幅要求、"宁可多搜"均不适用，深挖的充分性由任务书与预算档界定。

- **任务书即阶段四的出口**：定线结果、「断在哪」清单、样式、节次骨架（每节五样）、修辞主线、证伪条件（作为深挖靶子）；检验型论点要专门去挖支持裂落差的证据，不只带证伪靶子；
- **素材预算制**：预算档位在阶段四搭骨架时已分到节——深挖档要细节、决策时刻、人物；标准档要事实准确、时间线；浅探档只要关键事实+数字（产出 ≤800 字）；
- **去重规则**：子 Agent 任务书须附②素材地图中该方向已有的事实，注明"以下已有，只补＿＿＿"。已有事实不重新搜索；可在同一来源上深化提取（如②从赢商网拿到销售额，⑤从同一页追业态构成）。产出即落盘（见总览·调研底稿落盘）；
- **复核打分卡**：深挖必须坐实阶段一评估的落差判断；不成立则回报用户，按塌的是哪层退回——**落差本身塌了（事实不成立）回①重新评估，只是论点撑不住回③走降级阶梯或换维**；
- **来源纪律（与②分工：②用聚合源画地图，⑤用一手源补建材）**：
  - 必须联网；一手优先（官方公告／统计原文／政策文件 > 权威媒体原创 > 聚合转载）；
  - 每个关键事实标注 URL 和日期，数字注明口径与统计时点；
  - 搜不到就标「暂缺」，绝不编造；
  - 返回结构化笔记 ＋ 细节清单（3-5 个细节／故事点）；
  - 用户提供的采访或自有数据，按「用户供稿」标注、免公开 URL，但成稿须写明获取方式（如「据 XX 向本文口述」）；
  - 检索不到的缺口标「暂缺」并注明「用户可补」（纪律同①：只标注、不主动问、不停机）。

**搜索预算**（按④分配的预算档）：深挖档 ≤8 次搜索；标准档 ≤5 次；浅探档 ≤3 次。超预算须在笔记中说明理由。

**数据系列完整登记（同②）**：深挖遇到的时间序列同样登记完整序列＋同比增长率，追加进底稿「数据系列」节；②已登记过的补全其缺失年份，不重开一条。

**完成标准**：节次骨架中每节的「待挖目标」逐条有着落——有料标来源，无料标「暂缺」；遇到的时间序列均已完整登记。全部待挖目标有着落即完成，不因"还能搜"而追加。

子 Agent 提示词模板见 `references/research-agent-prompt.md`。

## 阶段六：核实与锁清单（轮三）

动笔前最后一道事实工序。与⑤分工：**⑤管"怎么拿"，⑥管"拿了什么能上桌"**——拿料的不核料：⑤带着"一定要挖到"的乐观，⑥要带着"这些料可能有诈"的疑心。

- **跨轴对账**：子 Agent 各扫各的扫描轴，矛盾只在汇总后可见——把各轮笔记里同一事实的不同说法摆在一起对（日期两说、数字两口径、口径出处冲突），冲突不解决不进清单；
  **时间序列另做口径核查**：底稿「数据系列」节里的每条跨年份序列，核两件事——①各年数值是否**取自同一份公报**（同一份内部必然同口径）；②跨公报拼接的，同一年份在新版公报里有没有被修订。发现修订的，以最新公报的历史值为准并标注，**不许把不同年份公报的绝对值直接连成一条线**（做法、红线与判例见⑨配图）。**注意不能用增速验算闭合来判断口径**——增速按可比口径、绝对值按当期口径，本就不互推；
- **口径终核**：所有要进文章的关键数字，逐条过口径（时点、来源、稀释前后、统计范围）；
- **锁清单**：产出「可写事实清单」——成稿只能使用清单内的事实。**准入条件（红线）：带〔待补URL〕的事实不得进清单**，②记的 `转述` 级须在此升为 `二手`／`一手` 并补齐 URL；升不上去的两条出路——不进正文，或进正文但在口径说明写明"来源为媒体转述，原始出处暂缺"（实战判例：太原古县城一文 2024 年 443 万人次即属后者）；清单字段从简：事实｜来源 URL｜日期｜口径｜对账状态（无冲突/两说已裁定）；清单即落盘（见总览·调研底稿落盘）。主线要用的人物/背景/细节，缺什么补什么，补不到的在文中诚实标注「暂缺」；
- **弹药盘点**：锁清单时按它过一遍节次骨架——哪个节的弹药最薄？薄的节还撑得起它在主线上的位置吗？撑不起→回⑤补该节，或回④砍节合并（预算是挖之前分的，这里是挖之后唯一的再平衡机会）；
- **一手素材愿望清单（全流程唯一一次主动向用户要素材，不阻塞）**：锁清单后提最多 3 条低成本请求——一个人物的 15 分钟口述、一个现场的照片或观察、一份用户手头的文件。每条注明用在哪节、能把哪句二手转引换成一手。用户给了，按「用户供稿」标注入清单；不给就照常成稿，不停机等。
  理由：案头稿的天花板就是"没有自己的人与现场"（判例：台账第 1、2 篇的人物全部是二手转引）。这份清单是唯一的抬升通道，而用户填它通常只要一刻钟。

## 阶段七：叙事成稿（两轮：写 → 扫）

**职责边界**：把定好的论点（③）、查实的材料（⑤⑥）、排好的骨架（④），组织成读者愿意读完的文字。

本阶段不负责让论点更对、材料更实、结构更顺，只负责**别在表达环节把前面攒下的东西损耗掉**。文章的力量来自判断的锋利（③）、证据的硬度（⑤⑥）、推进的紧凑（④），这一阶段能贡献的只有"不稀释"——所以它禁令多于指令，是设计如此，不是缺陷。

**红线：禁止用修辞补救上游问题。**论点软就回③，材料薄就标「暂缺」——不许用更强的修辞撑软论点，不许用漂亮话填材料空洞。这两种补救生产的是读着挺好但空的文本，最难被检查出来（可验收代理：第二轮的无出处断言排查含各节落点句）。

**入口**：可写事实清单（⑥）、节次骨架＋样式＋修辞主线＋认知任务（④）、反对者版本（①③，见调研底稿的打分卡与立意产出清单）。

本阶段规则的样文证据（五流派代表文章逐句拆解）见 `references/narrative-principles-evidence.md`。

### 第一轮：写（只管组织，不看禁词表）

写与查分两轮，是因为多条规则同时执行时，agent 会照顾显性的检查项而牺牲隐性的叙事——检查项可验收，叙事不可验收。所以写的时候只管下面六组组织规则，不看禁词表，禁词留给第二轮。

**1. 节内四件事**（四件都要有，顺序必须变）：

1. **落点**——这一节要说的那一句。默认放首句或次句；
2. **证据**——1–2 条带数字或带出处的事实；
3. **翻译**——把证据变成读者能感知的东西（数字翻译四法用在这里）；
4. **推进**——这一节与下一节的接口：留一个问题，或交出一个结论。这是主线在段落层的落实：每一节是主线上的一站，站与站之间要有路——每节结尾必须交出能引出下一节的东西，否则节与节只是并列，读者感觉不到在往前走。
   **接口有两头，下一节的开头同样受约束（红线）**：节首必须从上一节交出的那个结论或问题起步，**不许用程序性播报开头**——"先看…""接下来…""第二个…""下面说说…""再看一个角度"这类都是路标，不是接口。它们的共同特征是：**可以原样安在任何一节前面**。判废一问：把这句节首挪到别的节前，还成立吗？成立就是路标，重写。
   （实战判例：太原古县城一文七节，五节以"先看两组数字""先把最容易的解释排掉""第二个容易的解释是…""接下来是几条反对意见"开头，每节内部都合格，连起来却像四段拼贴——读者跟的不是推理，是作者的施工流程表。此病的根源是「推进」只约束了结尾、没约束开头。）

**防机械感（正面限制，可检查）**：四件事的顺序必须在节间变化，三种变体——**落点前置 / 证据前置 / 落点后置**；任意五节中不得有超过两节采用完全相同的顺序。落点后置只允许用于单节、且该节 ≤500 字。数同构节数即可验收，不需要申请许可（不用"破例标注理由"方案——理由可被无限编造）。

禁止：一节里堆三条以上并列证据（那是罗列不是叙事）；除落点后置变体外，把落点藏到节末。

**2. 开头（三选一，由④所选样式决定）**：

- **场景切入**（一个具体的时间地点场面）→ 故事群像式（分块）、本地纵深式（只写本地）；
- **落差亮相**（直接把两个对不上的数摆出来）→ 问题线索式（拆散）、双线对照式（穿插）；
- **热点立靶**（外地事件几句话说完，立刻转本地）→ 快评属性。

硬要求：**第一屏＝正文前 300 字**（含标点，与篇幅同口径），此范围内必须出现本文追问的那个问题，铺垫不许超过这 300 字。自检一问：**开头用的落差或事实，是不是全文最狠的一组？**不是就换（反例：澐玺文把最狠的"2.8%"落差埋在第四节）。保留禁令：禁止「我是在 XX 看到的这条新闻」式作者出场开场。

**3. 结尾（按认知任务分档）**：

- **规范型**：可以给主张，但须把代价说透；
- **描述/解释/检验/预测型**：落在「这件事还没完」——留问题，不给解决方案式空话。越界提醒：预测型论点以「应该怎么办」收尾，是超出本文论证范围的表态。

保留原要求：回扣修辞主线，从标题贯穿到结尾。

**4. 两条表达规则**（替代"镜头感"这类不可验收的心法）：

- **具体优于概括**：「三年关了 381 家店」优于「大规模收缩」；「2023 年 6 月的股东会上」优于「近年来」；「体育路那家」优于「某门店」。
  - 纪律：具体化只能用清单里已有的事实，不许为了具体而补细节——清单里只有「大规模收缩」，就写「大规模收缩」，不许推想出一个门店数。
  - 适用范围：只管"清单里有更具体的版本、却用了概括词"这一种情况。**判断句、对照句、翻译句不受此限**——文章的呼吸感来自判断与对照（如"死亡证明和出生证明开在同一天"），不来自概括。
- **动词优于形容词**：❌ 扩张激进 → ✅ 三年开了 47 家；❌ 资金链紧张 → ✅ 用预付卡的钱建了物流中心；❌ 前景堪忧 → 删掉，或换成一个可核查的事实。（这条是主观性自查「裸奔的判断」的正面表述：形容词是评价需要依据，动作是事实自带说服力。）

**5. 保留的原有规则**：

- **叙事驱动，不是罗列驱动**：每节有起承转合，关键数字全部具体化（「1411.87 亿」而不是「超千亿」）；
- **数字翻译四法**：对撞（25 万支 vs 186 支）、换算（≈ 一个二线城市一年 GDP）、拆解（7537 亿拆成境内境外）、落差（上海外贸 2.87 万亿 vs 阿里 3.77 万亿）。每处大数字至少用一种；换算优先翻到**人的尺度**——当事人的时间、收入、日常（"奖补 1.2 万"≈司机 34 天的流水），宏观参照（GDP/城市）退居其次（判例：台账第 1 篇）；
- **案例预算 + 只取一点**：**主料板块＝直接承载主推论点的节，辅料板块＝提供背景或过渡的节**——按④节次骨架第 1 项「功能」判定，不另起炉灶。主料板块案例不超过 3 个、辅料板块 1 个；每个案例只承担一个功能，取完就走，多出来的再好也进素材库，不进正文；
- **节奏**：短段为体（两三句一段为主），一句一段只用于落锤；
- **判断的正面表述**：断言直接下；推测必标注（「最大的可能是」「公开信息没有披露 X，我的推测是」）；敏感判断借信源之口（「XX 向 XX 解释」）；用「我们」不用「我」——代入感来自本地共同体视角（我们太原、我们手里的牌）和对本地细节的真知，不来自作者个人出场。
- **让步预算**：反对者版本集中在一处主场，给足篇幅，答完就走。
  全文的让步性转折（"公平地说""要说句公道话"之类）至多一处主场＋一处预告，不许逐节道歉。让步要放在你最强的论证**之前**，结尾的主权归论点（正例：出租车文用整节做反对者主场，然后收回主线；反例：澐玺文 2800 字里三连让步，读着像身后站着法务）。

**6. 篇幅**：以④所选样式的分档为准——问题线索式 3000–4500、双线对照式 3000–4500、故事群像式 3500–5000、本地纵深式 3000–4500、快评 2000–3500，字数按公众号后台口径（含标点）计。

分档的实测锚点：清博 500 篇样本研究显示 **3000–4500 字**推文阅读量理论最高、真叫卢俊头条中位数约 2900 字、攸克地产约 3600 字——三个锚点全部落在 2900–4500 区间。故事群像式因需容纳 3-4 个并列对象，上限放宽至 5000。

（**修订说明**：问题线索式与故事群像式原定 4000–6000，理由仅"因结构需要放宽"，**与上述实测锚点相悖且无证据支撑**，2026-08-15 按锚点下调。实战判例：太原古县城一文材料充分、论证完整，成稿 3016 字被旧档位判为"低于下限"，实则正落在阅读量最优区间——是档位定高了，不是文章短了。公众号深度文的合理上限由读者耐心决定，不由结构复杂度决定。）

超出所选样式上限的，**须在阶段四骨架阶段就说明为什么这个题必须更长**，不能到成稿时才发现超了；超过 5000 字必须向用户说明理由。

### 第二轮：扫（初稿完成后执行，**必做**）

**读取 `references/review.md` 后按其执行。**深度文两轮执行；快评第二轮并入阶段八第二审一次完成。

**动笔前不要加载 `references/review.md`**——详细禁词表与检查项若在写作时就在上下文里，会让写作照顾显性检查项而牺牲隐性叙事。第一轮只管上面六组组织规则。

第二轮总则（在此提示，细则见该文件）：**每项检查随检查产出证据，不接受裸 ✅**。共 7 项：AI 味禁区、聊天体与第一人称越界、引用编号、反对者版本进稿（红线）、无出处断言排查（强制举证）、事实来源核对（强制举证）、修辞主线回扣。
### 标题参考（发布前定，写作期间用工作标题）

- **禁区（唯一硬规则）**：公文腔对仗——「困境与机遇」「挑战与机遇并存」这类零信息量词组。
- **加分项（供掂量，不作门槛）**：具体数字 / 悬念追问 / 明确立场，占得越多通常越有点击相，但好标题可以破格。
- **诚实义务**：用户拿标题方案来问，按上两条如实评估优劣，不附和用户的第一直觉；最终选择权永远在用户。
- 标题若用了修辞主线，正文结尾要接得住；接不住就换直白的标题。

## 阶段八：双审（合规 + 主观性，发布前必做）

**读取 `references/review.md` 后按其执行**（本阶段细则全在该文件）。

成稿过两审，缺一不可；第二审可与阶段七第二轮合并执行（快评即合并）。**合并阶段不合并注意力**：第一审拦平台风险（会不会被吞），第二审拦语气风险（会不会被打脸）。

- **第一审：合规审查**——通用合规（极限词、平台规则）每篇必查；内容敏感性按题材触发；并复查两项上游承诺（①的角度级回避项、③的问题定性未漂移）。
- **第二审：主观性自查**——四类：越界的"我"、情绪越位、裸奔的判断、疑似阴阳。口诀：摆事实的尖锐是风格，没证据的暗示是风险。
**读取 `references/delivery.md` 后按其执行**（操作细则全在该文件）；同时用 `references/review.md` 的质检清单逐项打勾。

默认路径：成稿 Markdown → 用户确认内容 → 双版本交付 → 配图 → HTML 预排版 →（可选）推送草稿箱 /  PDF。

各环节的闸：

- **双版本交付**——详细版是母本，发布版由它压缩生成，**不得独立撰写**；发布版必留五类口径说明（单方叙述／效果图非实景／非官方称号／两口径并存／历史值经修订）；
- **配图·数据图表**——过价值门槛才出；数据补全先查底稿「数据系列」节；**红线**：补不到时按缺口画法（虚线＋标注），绝对值与增速不可互推，历史值会被修订须查；
- **配图·图片**——只许官方素材与开放图库两个渠道；效果图须标「非实景」；配不到就留空并写明原因；
- **推送草稿箱**——**红线：推送前必须向用户确认**；先 `--dry-run` 自查；只推草稿不做群发。

## 改稿复检（多稿迭代）

改稿是常态，复检按幅度分级，不搞一刀切。**分级规则与各级动作见 `references/review.md`**（结构性改动／段落级／字句微调／外部工具改稿四档）。其中一条要记住：**外部工具改稿（其他 AI、人工编辑）不论幅度，至少按段落级处理**——外来"润色"是敏感词回流的主要来源（实战验证）。

## 实战审计（每篇成稿后必做）

写完一篇文章，回头盘点约束发力情况：哪些规则在这篇里真起了作用（写进文章里的证据），哪些没出力。连续两篇实战未出力的规则，进入降级候选——默认层降工具层、工具层删除，向用户报告后执行。规则的去留由实战证据决定，不由偏好决定。

- **台账**：审计结果逐篇追加写入 `CHANGELOG.md`（篇名＋各规则出力/未出力）——"连续两篇"以此台账为准，没有台账的降级不算数；
- **豁免**：应急预案类规则（发布后补救顺序、评论区预判、`_已丢.md` 防重）价值在存在而非高频触发，不适用发力统计，不进降级候选。
