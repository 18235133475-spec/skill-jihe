# 阶段三：广撒网（轮一）（city-mirror 阶段文件）

> **入口**：①的概念定义
> **出口**：双图（认知地形图＋素材地图）＋数据系列＋钩子候选＋口径存疑清单
> **本阶段不管什么**：只画地图，不深挖、不判断哪个方向值得写——任何方向都不展开。
> **本阶段红线**：数据系列完整登记（含同比与出处公报）｜每条事实标源级｜产出即落盘
> **用户拍板点**：无
>
> 本文件只管本阶段怎么做。跨阶段的约定见 SKILL.md「阶段路由与接口总表」；三层制与贯穿全程的骨干规则同样在 SKILL.md，冲突时以其红线为准。

## 一、这一步做什么

定结构之前，先看清两张地图：别人说过什么，事情本身有什么。宽而浅。

**宽而浅**：本轮不深挖，任何方向都不展开。

## 二、怎么做

**一批搜索，两种归档——不是两轮搜索。**四步走完，产出是地图不是建材。

### 第一步：定三轴分工与执行方式

三轴各管一个视角：

- **纵向**：话题自身的生命历程（本地与外地双边）；
- **横向**：当下截面的同类/竞品坐标；
- **交汇**：格局与政策脉络、本地手里的牌。

**默认派 3 个子 Agent 并行**，与三轴一一对应，单 Agent 产出 ≤1500 字。素材特别厚时可加第 4 个，但须在任务书里写明它补的是哪一轴的哪个缺口——**不写明的第 4 个不许开**。

**宿主不支持派子 Agent、或用户要求不派时，走单人执行降级路径**：主 Agent 依次跑完三轴，每轴单独成节记录，**轴与轴之间不混着搜**——三轴的价值在于视角分工，混着搜会退化成一轮泛搜。产出格式与派 Agent 时完全一致（三轴笔记＋双图），底稿中注明"本轮为单人执行"。**不派 Agent 不等于跳过三轴。**

### 第二步：按轴扫，用宽覆盖的源

画地图用覆盖面宽的源，不追一手原文——**画地图要的是覆盖面、不是精度**，精度留给⑥深挖追一手：

- 行业媒体综述 / 数据聚合平台 > 权威媒体单篇报道 > 官方文件原文；
- 聚合源引用的数字按原文记录即可，口径终核留给⑦——③只管发现，不管终核；
- 本条覆盖子 Agent 模板中"一手来源优先"的默认优先级。

预算见「三、预算」。**搜完仍有空白的，标「暂缺」留给⑥，不加搜。**

### 第三步：边扫边登记（红线，漏了要回头重搜）

**每条事实当场标「源级」**——`一手`（官方原文/年报/评级报告，须带 URL）／`二手`（权威媒体原创，须带 URL）／`转述`（聚合摘要，可暂记媒体名＋日期，URL 标〔待补〕）。

**「待补」的补齐时点是⑦，不是⑥，也不许拖到成稿**：⑦核实锁清单时，凡要进正文的事实，`转述`级必须升到 `二手` 或 `一手` 并补齐 URL；升不上去的，要么不进正文，要么在口径说明里写明"来源为媒体转述，原始出处暂缺"。**清单里带〔待补〕的事实不得进入可写事实清单**——这是⑦的准入条件，不是建议。

**搜到时间序列或多对象同指标数据时，登记完整序列**（社零、GDP、人口、销售额、房价等），不只登记正文可能用到的那几个点。正文只会截取其中两三个点，但⑩出图需要完整序列——不完整就得回头重搜，成本远高于登记时顺手多记几行（实战教训：太原社零③只记了正文要用的三年，⑩出图时重搜 6 次仍未补齐）。格式见「四、产出」。

**登记三项纪律**：①**注明出自哪一份公报**——同一份内部必然同口径，跨公报拼接才需担心修订；②**同比增速一并记**，但只作参考，**不得用来反推绝对值**（增速可比口径、绝对值当期口径）；③发现同一年份在新旧公报里数值不同的，**两个值都记下并注明版本**。

### 第四步：把同一批材料归两次档，组装双图

同一批材料切两次，得到两张地图：

| 归档方式 | 切的对象 | 维度 | 判断标准 |
|---|---|---|---|
| **认知五段** | 别人的报道（媒体怎么写） | 描述·解释·检验·预测·规范 | 哪段拥挤／空白／有分歧 |
| **素材六维** | 事实本身（事情有什么） | 人·财·物·空间·时间·制度 | 每条是有出处的事实，无料略过 |

五段：描述（这是什么）、解释（为什么是现在）、检验（真的是这样吗）、预测（接下来会怎样）、规范（应该怎么办）。
六维：人（人物/使用者）、财（账本/资金）、物（设施/产品）、空间（区位/格局）、时间（节点/周期）、制度（政策/规则）。

双图的具体形态见「四、产出」。**不受②的评估结论指挥**——③只管发现，不去替②那条落差找证据。

## 三、预算

- **派子 Agent 时**：每个子 Agent ≤5 次搜索（WebSearch），每次搜索深入提取 ≤3 个页面（FetchURL）；
- **单人执行时**：**总计 ≤12 次**（3×5 的八折，单人无并行重复损耗），单次深入提取仍 ≤3 个页面。

预算是上限；**搜完仍有空白的，标「暂缺」留给⑥，不加搜**。子 Agent 提示词模板见 `references/research-agent-prompt.md`。

## 四、产出

### 子 Agent 返回格式

按子任务分节的笔记（每条事实带来源）+ 每条主要发现打认知段标签（【描述】/【解释】/【检验】/【预测】/【规范】）+ 扫描轴内主流判断记录（一句话+来源，标注趋同/分歧）+ **素材归档（六维分桶，每条带出处，无料的维度略过）** + 钩子候选（至少 1 个）+ 一句话盘点"本轴内哪个认知段料最多、哪个空白"。

### 双图（主 Agent 组装）

1. **「认知地形图」**：五段 × 密度（多/少/空白）× 趋同度（趋同/有分歧）× 代表作链接，外加钩子候选清单。判断标准：料厚且趋同＝别去（挤进去是第 101 篇通稿）；料薄、空白或有分歧＝发力点候选。趋同/分歧是子 Agent 的一线判断，组装时抽查出处。
2. **「素材地图」**：人/财/物/空间/时间/制度六维，每维下列出有出处的事实与载体——写文章能用的切入点基本都在这六个筐里。

### 数据系列（写进调研底稿「数据系列」节）

```
指标: 太原社会消费品零售总额
口径: 全市｜当年价｜含餐饮
序列: 2021=1873.90(+13.2%) | 2022=1761.40(-6.0%) | 2023=1912.88(+8.6%) | 2024=1946.92(+1.8%) | 2025=2365.53(+4.7%)
出处: 太原市统计局《2025年国民经济和社会发展统计公报》图4 + URL ← 同一份公报的连续序列，内部同口径
备注: 2019 年另有两个值——2019年公报 1952.81，2020年公报图5 已修订为 1769.01，跨公报取值以新版为准
```

注意：本轮不深挖，任何方向都不展开。**它的产出是地图，不是建材。**产出即落盘（见总览·调研底稿落盘）。

## 五、回退

**本阶段无回退路径。**③只管发现，不下判断——扫出来的空白与分歧都是④交叉表的原料，不构成对上游的否决。

搜完仍有空白的**不回退也不加搜**，标「暂缺」留给⑥。

## 六、完成标准

素材地图六维每维 ≥1 条事实或标「本维无料」；认知地形图五段每段标出密度与趋同度；遇到的时间序列均已完整登记；每条事实均已标源级。地图允许空格，但空格必须是标出来的，不是漏掉的。**收尾自检**：三轴各盘一遍——纵向时间线有没有明显断层？横向同类坐标有没有明显遗漏？交汇轴本地手里的牌扫全了吗？
