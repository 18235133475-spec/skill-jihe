# 审稿与验收（city-mirror 参考文件）

> **何时读取**：初稿写完之后。**不要在动笔前加载本文件**——详细的禁词表与检查项若在写作时就在上下文里，会让写作照顾显性检查项而牺牲隐性叙事（这正是 city-mirror「第一轮只管组织，不看禁词表」那条纪律的物理保障：靠自律不可靠，靠文件边界才可靠）。
>
> **覆盖**：⑦第二轮扫查 → ⑧双审（合规＋主观性）→ 改稿复检 → 交付前质检清单。
>
> **与 SKILL.md 的关系**：本文件的规则服从 SKILL.md 的三层制（红线/默认/工具）。两者冲突时，以 SKILL.md 的红线为准；本文件只细化「怎么查」，不改变「查什么算过」。

### 第二轮：扫（只管检查，不重新构思。深度文两轮执行；快评第二轮并入阶段八第二审一次完成）

**总则：每项检查随检查产出证据，不接受裸 ✅。**禁词类给逐词扫描结果（词：命中行号或零），事实类给映射表；申报无证据视为该项未执行（判例：台账第 2 篇两处自查虚报，均为裸 ✅，详见台账）。

1. **AI 味禁区**：禁用「首先/其次/最后」「综上所述」「值得注意的是」「说白了」「本质上」「换句话说」「赋能」「抓手」「闭环」「在当今……的时代」；
2. **聊天体与第一人称越界清零**：按⑧第二审「裸奔的判断」「越界的"我"」两个类目扫（禁例与处理见彼处，此处不重述）；
3. **引用编号**：正文数据后用〔1〕〔2〕……标注，文末「信息来源」逐条列出（媒体、日期、URL），再加「数据口径说明」一节统一交代关键数字的口径。**这是「详细版」的要求，成稿一律先按此写全**——发布版由它压缩生成（见⑨双版本交付），不得反过来；
4. **反对者版本进稿（红线）**：阶段一当事人测试与立意三测标记的"反对者说得通的版本"必须写进正文，**且须出现在它所反对的那个论断所在节内**，不得压缩成一句孤悬文末（机理见①落差自检——进稿的位置决定它是被如实对待还是被形式满足）；并核让步预算：让步性转折至多一处主场＋一处预告；
5. **无出处断言排查（强制举证）**：逐句扫描全文的**因果句、比较句、否定句与各节落点句**（无出处断言的四个高发区——落点句无支撑即"修辞补救上游"的显影），每句在可写事实清单中找对应支撑——有支撑标〔n〕；无支撑但属本文论点，改标推测；无支撑且非论点，删除。产出「无出处断言清单」；清单为空的，须逐句说明四类句各有几处、分别由哪条材料支撑——举证代替声明；
6. **事实来源核对（强制举证）**：产出「成稿事实→清单编号」映射表——映射不全＝核对未执行；清单外事实要么补录进清单（含出处、过口径）要么删除，不存在第三种去向。常识性事实（地理位置、城市行政层级等无争议的公共知识）不受此限，但判断性对比（A 比 B 强/弱/好/差）仍须有清单内数据支撑；
7. **修辞主线回扣**：标题若用了修辞主线，结尾是否接住。
8. **节间衔接测试（强制举证，新增）**：叙事不可验收，所以改成可验收的形式——**抽出每一对相邻节的「上节末句 ＋ 下节首句」，连起来读，产出「节间接口表」**（逐对列出：上节末句／下节首句／判定）。
   两条判废标准：
   - **路标判定**：下节首句若能原样挪到任意其他节前面仍然成立，它就是程序性播报（"先看…""接下来…""第二个…"），不是接口 → 重写；
   - **断链判定**：末句与首句连读不成话，说明上节没交出东西或下节没接住 → 补接口；
   **表中每一对都须给出判定，全判"通过"而不出表＝该项未执行。**
   （判例：太原古县城一文，七节中五节首句为程序性播报，每节内部均合格，连起来却像拼贴。此项检查即为拦截该病而设。）
10. **内部术语外泄扫描（逐词，新增）**：本 skill 的工作术语**只用于流程内部，不许出现在成稿正文**。逐词扫描下列词，给命中行号或零：
   **亮尺／尺子（作方法论比喻时）、落差、双图、认知五段、认知任务、单引擎、主线／修辞主线（指本文方法时）、打分卡、可写事实清单、素材地图、认知地形图、试讲、节内四件事、待挖清单**。
   处理：命中的一律改成读者的话说同一件事——"亮尺"→"拿什么标准判断／要问哪几个问题"，"落差"→"对不上的地方"，"维度"→"问题／条"。
   **豁免**：这些词在本义上使用时不算（如"旅游公路主线"的主线、"三个维度的坐标系"确实在说几何维度）。须逐条给"属术语外泄／属本义使用"的判定。
   （实战判例：太原古县城一文写出"用来量的那把尺子本身选错了"，"尺子"来自④检验型的内部动作名「亮尺—量—报告结果」。此前已有澐玺文"缺一把尺子的感慨"同类判例，但只修了个案未立通则，故复发。**工作术语是给流程用的脚手架，不是写作词汇；脚手架留在成品上就是生硬**。）

   **10b. 程序性自述扫描（同属外泄，但泄的是动作不是名词）**：除术语外，**不许把"我正在执行哪条规则"写进正文**。
   核心原则：**规则约束的是文章要包含什么，不是文章要声明自己包含了什么。**
   高发句式（逐句扫，命中即改）：「有几条反对意见**必须正面接住**」「这是**本文要追的问题**」「**接下来是**…」「**先把**最容易的解释**排掉**」「按流程」「**需要指出的是**」「本文将从三个方面」。
   改法：**做那件事，别说你在做**——反对者版本直接写成让步句（"这么比，其实有几处不公平"），追问直接抛出（"更大更贵的那一座，人反而更少"，不必再加"这是本文要追的问题"），排除法直接给答案（"最省事的答案是时间"）。
   （实战判例：**同一句式在两篇里连续出现**——万象天地文"这里有一个反对意见必须正面接住"、太原古县城文"有几条反对意见必须正面接住"，均为⑦「反对者版本进稿」这条红线的动作名外泄。v4.30 立第 10 项时只列了**名词术语**，扫不到**句式**，故未拦住。用户读稿指出："你找一些反面的观点来做判断，这是写作流程，不是最终输出。"）

9. **极限词误报豁免（配合⑧第一审）**：⑧的极限词扫描按词命中，会把行文序数与普通用法一并报出。**判定原则（不用列举法——列举必漏）：只有用于抬高本文所写对象的才算宣传性极限词。**看两件事：①这个词修饰的是不是本文的主体对象；②去掉它，对该对象的评价会不会降低。两条都是"是"才须挂来源。
下列情形一律豁免：作序数词（"第一条""第一年""第一家"）；作程度副词修饰非主体对象的普通描述（"最容易的解释""最常被指认""最近""最省事"）；固定术语与政策名词（"最高限价""最惠国"）；引述他人原话内的极限词（已在引号与来源内）。**须判定而非直接删**——逐条列出命中位置与"属宣传性极限词／属普通用法"的判定，属前者才要求挂来源或改写。

## 阶段八：双审（合规 + 主观性，发布前必做）

成稿过两审，缺一不可；第二审可与阶段七第二轮合并执行（快评即合并）。**合并阶段不合并注意力**：第一审拦平台风险（会不会被吞），第二审拦语气风险（会不会被打脸）。

### 第一审：合规审查

分两层：通用合规每篇必查，内容敏感性按题材触发；并复查两项上游承诺——阶段一评估定下的角度级回避项是否守住，阶段三「问题定性」是否未漂移（全文追问的仍是 Y，没有滑成质疑 X）。

#### 第一层：通用合规（每篇必查）

**1. 广告法极限词扫描**
扫描词表：「最、第一、唯一、首个、首选、顶级、国家级、世界级、全球领先、100%、史上」等。**先按⑦第二轮第9项做误报判定**（序数词、日常程度副词、引语内极限词均豁免），判定为宣传性极限词的才进入下面的处理。极限词不一律删，但必须挂来源——有权威出处的，保留为事实引用并注明；没出处的，改掉或删掉。非商业推广文章的广告法适用虽有争议，但平台机器审核按词扫，宁可全过一遍。

**2. 微信平台规则扫描**
- **时政资质**：无新闻许可不采编时政新闻，只引用公开报道并在开头声明（见下）；
- **证券资质**：不荐股、不预测股价、不暗示买卖——写上市公司只谈产业与财报事实，不给任何投资指向；
- **不实信息**：关键数据均有出处（与阶段六「可写事实清单」衔接）；
- **名誉权**：写企业/人物的负面事实，定性表述只能用来源原词（法院名单、官方通报、权威媒体原话），不自创贬义标签；
- **标题党**：标题与正文一致，不夸大、不误导。

#### 第二层：内容敏感性（涉政题材时执行）

- **高危（必改）**：国家领导人讲话后紧跟任何轻慢/调侃表述；点名现任高级别官员（即使内容中性，改为「时任 XX 职务」）；对领导人表述做任何延伸解读。
- **中危（与用户确认）**：落马官员与热点事件并置（最稳写法是匿名化或直接删除案件细节，把论点改成「机制比个人可靠」）；对本地政府政策目标的批评性对比（数据必须真实且落点建设性）；领导人名字全文出现不超过 2 次且仅为正面事实引用。
- **低危（保留）**：官方媒体已公开报道的反腐案件细节（不加评论性形容词）；历史困难时期的负面数据（有官方来源 + 上下文有改革动作平衡）；企业负面事实（有权威来源即可）。

#### 发布前必做四件事

1. 开头加声明：「本文基于公开报道与官方数据整理分析，数据口径与信息来源见文末」；
2. 标题和摘要里不出现领导人姓名、落马、受贿等词；
3. 时效数字复核：行情类数字（市值、股价、浮盈）复核截止日期，已明显过时的改口径或删；
4. 评论区预判：地域对照文天然引战，准备一条置顶评论（重申"对比谈机制、对事不对人"的立场），必要时开评论精选。

发布后补救顺序（若被限流/删除，按此做减法）：①落马官员段 → ②敏感时间并置 → ③案件金额细节。

### 第二审：主观性自查

把全文的主观表达分四类：

- **越界的"我"**（第一人称个人场景、"我是在 XX 看到的"）：删，或改写为「我们」视角。作者情绪可以保留，但要长在共同体口吻里，且强度遵守下面的情绪越位标尺。
- **情绪越位**（情绪强度超出本地与事件的实际关联和量级）：判别标准是"这份情绪轮不轮得到我们"——关联直接、量级相当，可重笔（痛心、扎心）；关联间接，轻笔（"刺眼""值得对照"）；无关联，只写事实不写情绪。情绪宁轻勿重：轻一分是克制，重一分是碰瓷，尬比淡更伤文章。
- **裸奔的判断**（有结论无依据、推测未标注）：补证据、标注推测、或借信源之口；清空「我觉得」「不一定对，姑且一说」。
- **疑似阴阳**（事实不明说、靠语气暗示；双重否定反讽；无来源的否定断言）：逐一判定——有事实直接支撑的尖锐可以留；无来源支撑的否定断言必改；反讽能直写就直写。

判别口诀：摆事实的尖锐是风格，没证据的暗示是风险。

#### 判别实例表（来自实战）

| 判定 | 实例 | 处理 |
|---|---|---|
| ✅ 保留 | 「就是这个烂摊子上」（上文已引：七年亏损、专家撤走、利润 1 元指标） | 有事实垫底的口语压缩，欲扬先抑 |
| ✅ 保留 | 「种子撒出去，开花在太原，结果在常州、在北京、在央企的账上」 | 比喻式判断，前文每个案例均有出处 |
| ⚠️ 软化 | 「文件写得不可谓不狠，奖励给得不可谓不痛快」 | 双重否定反讽 → 直写「目标定得不低，奖励给得也不慢」 |
| ⚠️ 软化 | 「亏一个项目就要写检查」 | 想象中的场景无出处 → 删或改「层层说明」 |
| ❌ 必改 | 「我觉得取决于三个改变。不一定对，姑且一说」 | 聊天体对冲，违反判断三工具 → 改为断言，或「这三个改变是我的推测，依据是……」 |
| ❌ 必改 | 「容错的文件停在纸上」 | 无来源的否定断言 → 改为有据表述「容错刚写进文件，还没有公开的落地案例」 |

## 改稿复检（多稿迭代）

改稿是常态，复检按幅度分级，不搞一刀切：

- **结构性改动**（增删板块、换样式、改主线）：视同新稿，重跑阶段七第二轮与阶段八全文审查，重核全部引用编号。
- **段落级改动**（增删段落、改写论证）：重扫改动段落的合规与主观性，重跑改动段落的无出处断言排查，重核受影响的引用编号。
- **字句微调**（错别字、标点、个别措辞）：只扫改动句的敏感词与口径，无需全文重跑。
- **外部工具改稿**（其他 AI、人工编辑）：不论幅度，至少按段落级处理——外来"润色"是敏感词回流的主要来源（实战验证）。
- 交付物（HTML 或 PDF）按最终定稿重新生成，文件名与稿次对应（如 `xxx_三稿.html`），旧版及时清理，避免发错版本。

## 质检清单（交付前逐项打勾）

只装能验收的闸，不装应该早已发生的动作。「机制落点」「对事不对人」「故事有具体的人」这类设计属性在各阶段执行中保证，不在此重复。

- [ ] 数据口径：关键数字多源核实过，全部来自「可写事实清单」，文末有「数据口径说明」？
- [ ] 底稿：调研底稿已落盘（打分卡/双图/数据系列/立意产出清单＋拍板记录/线索对照表/深挖笔记/可写事实清单齐，章节对照 `references/draft-template.md` 无缺）？
- [ ] 概念界定：核心概念已界定且无歧义，全篇共用同一口径，读者不熟的词已给读者版解释？
- [ ] 引用：详细版正文每个关键数据有〔n〕，与文末来源一一对应？发布版由详细版压缩生成（非独立撰写），已去〔n〕，五类必留口径说明齐？
- [ ] 立意：经用户拍板，论点为带方向的陈述句，三测通过（证伪条件/反对者理由/可证判定齐）？
- [ ] 结构：主线经五线试讲定线（线索对照表+「断在哪」清单在手），五问复检已记录，样式与修辞主线经一次呈报确认？
- [ ] 单引擎：每节都能一句话答出「如何推进主线」？
- [ ] 成稿组织：每节四件事齐、顺序有变化（任意五节同构不超过两节）、节间有推进接口？开头一屏内出现本文追问的问题且用的是全文最狠的落差？结尾未超出认知任务允许范围？第二轮各项均附证据（无出处断言排查含落点句、事实→清单映射表已产出）？
- [ ] 落差：所用落差均过当事人解释测试，反对者版本已进稿且在让步预算内（一处主场＋至多一处预告）？
- [ ] 时效：论据已标年份，过时素材已降级或反转进检验段？行情类数字已复核截止日期？
- [ ] 合规：两层扫描全过（极限词均有来源、无荐股表述），涉政题材的高危项为零，标题摘要无敏感词，角度级回避项与问题定性守住，置顶评论已备？
- [ ] 主观性：无来源的否定断言、情绪越位已清零？
- [ ] 声明：开头有「基于公开报道整理」？
- [ ] 标题：无公文腔；若用修辞主线，正文结尾接得住？
- [ ] 篇幅：在所选样式的分档内（含标点口径，④概算时已对齐）？超 6000 字已向用户说明理由？
