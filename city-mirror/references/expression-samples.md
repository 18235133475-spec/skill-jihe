# 表达样本库（段落级）

> **用途**：⑧ 写作中卡在"这个意思该怎么落笔"时查。按 **⑧ 的动作**分格，不按作者、不按流派——卡在哪个动作，翻哪一格。
> **与 `pattern-samples.md` 的分工**：那边是**篇级**（一篇文章怎么搭），这边是**段级**（一段话怎么写）。

## 两条纪律（分开，效力不同）

1. **内容不得挪用（红线）**：本库存的是**原句**。写作时只学做法，**不得整句或整段搬进正文**，也不得换几个词后搬。引用他人原句须标出处并置于引号内。
2. **手法可学，腔调不模仿**：具体做法（怎么亮尺、怎么把决策拆成选择题、怎么把大数字翻到人的尺度）应当学；某个号的整体腔调不学——本 skill 的说话位置是"多年工作生活在太原的人"，写出来不应让人认出是在学谁。

## 喂养规则

**这个库是活的，靠提名补充。分工**：用户提名（看到一段好的，给出原文）→ agent 拆解手法、定动作格、判是否达门槛 → 报给用户（够格／不够格，够格的话替换掉哪条）→ 用户裁决 → 入库。**拆解那步必须由 agent 做**：没有拆解，段落就只是段落，学不会迁移。

**入库门槛（三条全过才收）**
1. **落得进某一格**——对应 ⑧ 的一个具体动作。落不进的不收，不为它新开格；
2. **拆得出可复用的做法**——能用一句话说清"它是怎么做到的"，而不只是"读着舒服"；
3. **无程序性自述**——不写"这里需要引入一个评价框架""接下来我们看"。含这类表述的一律不收。

**入库格式（三段，缺一不收）**

```
### 〔动作格〕· 〔手法名〕
> 原文段落（一字不改）

拆解：〔它是怎么做到的，一到两句〕
出处：〔作者/媒体/日期；无出处标"出处待补，仅作手法参照，不得整句挪用"〕
```

**容量与淘汰**：**每格最多 3 条**。满了只能替换，不能叠加——收进新的一条，同时指明踢掉哪一条并说明理由。全库上限约 2,000 tokens；超了先砍条数最多的格。

**禁止事项**：**不得改动分格依据**。格子对应 ⑧ 的动作，⑧ 改了才跟着改。本库不自创分类——一旦自创，它会与阶段文件分家（判例：`pattern-samples.md` 的"四具名样式"停在 v4.0 的两轴，而 ⑧ 的轴早已变过，直到 v4.42 才发现）。

## 格一：亮尺（⑧第一步·二 框架先行）

检验型与规范型必需——先说清"拿什么量"，否则"站不站得住""该怎么办"没有依据。

### 亮尺 · 换口径式

> 城市交通早晚高峰拥堵，就一定是管理不善？这倒未必。需要看人们的出行需求，在多大程度上得到了满足。「公交优先」就是一个向度。

拆解：立靶（读者默认的那个归因）→ 一句否定 → 换一个衡量口径 → 落到一个具体维度。四句走完，**没有一句在说"我要换个标准了"**。
出处：出处待补，仅作手法参照，不得整句挪用。

### 亮尺 · 拆成选择题式

> 雨洪的应对，思路比技术更重要……决策者需要做出判断，其实只要自问三个问题：面临洪水威胁，是听之任之，还是采取行动？应对洪水威胁，有什么资本，可调用多少资源？目前想大力投入的，是灰色基础设施，还是绿色基础设施？

拆解：把一个说不清的判断，做成一串**能回答的二选一**，且三问有序——意愿（做不做）→ 能力（有多少本钱）→ 方向（往哪投）。尺子不是抽象维度，是三道具体的选择题。
出处：出处待补，仅作手法参照，不得整句挪用。

## 格二：把大数字翻到人的尺度（⑧第二步·原则）

_待填。_ 收的是：把亿元、平方公里、百分比换算成当事人的时间、收入或日常的写法。

## 格三：读者不熟的词给一句人话解释（⑧第二步·原则；①读者版解释）

_待填。_ 收的是：一句话说清专业词，且**不晚于首次实质使用**的写法。

## 格四：开头（⑧第二步·原则）

_待填。_ 收的是：用最狠的落差起手、300 字内亮出追问的问题，且不用"随着……的发展"这类开场的写法。

## 格五：让步（⑧第二步·禁令）

_待填。_ 收的是：把反对意见写成自然让步、而不是写成流程声明的写法。反例（不收）："有几条反对意见必须正面接住"。

## 格六：案例只承担一个功能（⑧第二步·原则）

_待填。_ 收的是：一个案例只取一个点、取完就走，不铺成小传的写法。

## 格七：结尾（⑧第二步·禁令）

_待填。_ 收的是：检验型落到"这件事还没完"、规范型给主张并说透代价的写法。不收解决方案式空话。
