# 调研底稿章节骨架(`文章名_调研底稿.md` 模板)

> 用途:开新选题时按此骨架建底稿文件,逐轮追加、只增不删。每节是一个落盘闸——节存在但内容为空,说明该阶段没做或没落盘,审计按缺项记。
> 判例:台账第 2 篇整个阶段四产物(线索对照表/断在哪/节次骨架/拍板记录)漏落盘,台账自称"✅"而无证据——有模板留节,漏项在写作时就会显形。

```markdown
# 〔话题名〕 · 调研底稿

> 逐轮追加,只增不删。skill 版本:vX.X。开始日期:YYYY-MM-DD。

## 阶段一 · 概念界定
（双向检验结果 / 用户选定项 / 定义与官方口径出处 / 是否需读者版解释）

## 阶段一 · 选题评估打分卡
（回扫养题库结果——只认 `养题库/` 目录实体文件 / 钩子盘点 / 【否决】含角度级回避项 /
【载体】/【落差】各条+两边出处+当事人测试与反对者版本 /【父子】/【时效】/【在地】/【结论】）

### 拍板记录①
（呈报了什么、用户选了什么、日期——一行即可,没有这行=没拍板）

## 阶段二 · 广撒网双图
（认知地形图:五段×密度×趋同度×代表作 / 素材地图:六维每条带出处 / 钩子候选池 / 口径存疑清单）

## 阶段三 · 立意产出清单
（每候选:论点/位置/认知任务/证伪条件/反对者理由/可证判定 / 落选者去向 / 待挖清单 /
拍板前三道检查:问题定性、对照辨性质、贴身检验）

### 拍板记录③
（候选清单呈报、用户选定的主立意与搭配）

## 阶段四 · 结构产出
（线索对照表:五线×硬材料数×无料处数×断在哪 / 定线判定 / 五问复检记录:一致或不一致 /
样式推导 / 节次骨架:每节五样〔功能/挂线/弹药/待挖预算/概算字数,合计对样式档〕/ 修辞主线方案）

### 拍板记录④
（样式+修辞主线一次呈报、用户确认结果）

## 阶段五 · 深挖笔记
（按任务书条目编号返回 / 复核打分卡结论 / 计划外发现单列）

## 阶段六 · 核实与锁清单
（跨轴对账裁定逐条 / 可写事实清单:事实|来源URL|日期|口径|对账状态 / 弹药盘点 /
一手素材愿望清单≤3条及用户响应 / 暂缺清单）

## 阶段七/八 · 成稿与双审记录
（第一轮:变体排布/翻译用法/案例预算 / 第二轮:逐项附证据——禁词逐词结果、
无出处断言清单、事实→清单编号映射表、让步预算核对 / 第一审+发布前四件事+置顶评论文案 / 第二审四类)

## 质检清单勾选结果
（16 项逐项,过/不过+一句说明）
```

## 使用纪律

- 建文件时把全部节标题一次写齐,内容随阶段推进填入——空节可见即欠账可见;
- 拍板记录三处是最容易漏的:没有记录的"用户已确认"在审计中一律不采信;
- 快评轻流程用简化版:概念界定 → 打分卡+拍板① → 广撒网简版 → 拉简版交叉表+拍板③ → 核实简版(迷你清单) → 成稿+双审记录 → 质检。
