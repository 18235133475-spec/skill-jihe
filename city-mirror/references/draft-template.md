# 调研底稿章节骨架(`文章名_调研底稿.md` 模板)

> 用途:开新选题时按此骨架建底稿文件,逐轮追加、只增不删。每节是一个落盘闸——节存在但内容为空,说明该阶段没做或没落盘,审计按缺项记。
> 判例:台账第 2 篇整个阶段五产物(四段对照表/断在哪/节次骨架)漏落盘,台账自称"✅"而无证据——有模板留节,漏项在写作时就会显形。

```markdown
# 〔话题名〕 · 调研底稿

> 逐轮追加,只增不删。skill 版本:vX.X。开始日期:YYYY-MM-DD。

## 阶段一 · 概念界定
（三类歧义检验结果〔同名不同物/相近概念/口径歧义〕/ 用户选定项 / 定义与官方口径出处 / 是否需读者版解释）

## 阶段二 · 选题评估打分卡
（【否决】概念级 3 条+角度级 5 条逐条判定,含角度级回避项 /
【载体】/【落差】各条+两边出处+当事人测试与反对者版本 /【体量】/【时效】/【在地】/【结论:写|不写】）

### 拍板记录②
（呈报了什么、用户选了什么、日期——一行即可,没有这行=没拍板）

## 阶段三 · 广撒网双图
（认知地形图:五段×密度×趋同度×代表作 / 素材地图:六维每条带出处 / 钩子候选池 / 口径存疑清单）

## 数据系列（③⑥ 共用,持续追加;⑩配图直接取用,免重搜）
（每条一块:指标 / 口径 / 序列〔年份=值(同比%) 逐年列全,不只列正文用得上的〕/ 来源+URL / 备注
同比增长率必须一并记——⑦对账与⑩出图据此验口径链是否闭合）

## 阶段四 · 立意产出清单
（定性一句话 / 合格论点全部列出,每个:论点/位置/认知任务/证伪条件/反对者理由/可证判定 /
待挖清单:格子+缺口+为什么挖）

### 拍板记录④
（候选清单呈报、用户选定的主立意与搭配）

## 阶段五 · 结构产出
（四段对照表:四段×硬材料数×无料处数×断在哪 / 否决门槛判定 /
节次骨架:每节四样〔功能/挂主线哪一环/已配弹药/待挖目标+预算档位〕/ 单引擎检查结果）

## 阶段六 · 深挖笔记
（按任务书条目编号返回 / 复核打分卡结论 / 计划外发现单列）

## 阶段七 · 核实与锁清单
（跨轴对账裁定逐条 / 可写事实清单:事实|来源URL|日期|口径|对账状态 / 弹药盘点 /
一手素材愿望清单≤3条及用户响应 / 暂缺清单）

## 阶段八 · 成稿与双审记录
（第一步定表达:骨架形态/框架先行判定/修辞主线/概算字数+承载力校验 /
第二步写:变体排布/翻译用法/案例预算 / 第三步扫:逐项附证据——禁词逐词结果、
无出处断言清单、事实→清单编号映射表、让步预算核对 / 第一审+发布前四件事+置顶评论文案 / 第二审四类)

### 拍板记录⑧
（骨架形态+修辞主线一次呈报、用户确认结果）

## 质检清单勾选结果
（19 项逐项,过/不过+一句说明）
```

## 使用纪律

- 建文件时把全部节标题一次写齐,内容随阶段推进填入——空节可见即欠账可见;
- 拍板记录三处(②④⑧)是最容易漏的:没有记录的"用户已确认"在审计中一律不采信;
