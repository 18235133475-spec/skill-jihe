# 结构样文库（篇级）

> **用途**：⑧ 定骨架形态时查两样——**一、结构幻觉清单**（确认没造出现实中不存在的结构）；**二、样文索引**（想看真实文章怎么处理某个坐标时调阅）。
> **不是选样式的地方。**⑧ 明写骨架形态"由⑤的四段骨架和证据分布决定，不预设、不硬凑"。本库只供参照与排错，不提供可套用的模板。
> **与 `expression-samples.md` 的分工**：那边是**段级**（一段话怎么写），这边是**篇级**（一篇文章怎么搭）。

## 两条纪律（分开，效力不同）

1. **内容不得挪用（红线）**：不得搬用样文的事实、案例、原句。
2. **手法可学，腔调不模仿**：结构处理方式可以学；某个号的整体腔调不学。

## 坐标（与 ⑧ 第一步·一 同一套，本库不得自创分类）

- **轴一 · 读者跟着什么走**：对象／时间／空间／流转
- **轴二 · 外地材料怎么进来**：拆散／穿插／分块／只写本地

追问是全篇主线（⑤已定），不进坐标轴。**样文按坐标归位，不按"式"命名**——v4.0 的"四具名样式"已废止：它是旧两轴的投影，而轴一在 v4.39 变过（追问上升为主线），标签与阶段文件早已脱钩。

## 一、结构幻觉清单（主要用途）

**结构约束放松之后，这份清单比正面样文更要紧**——它防的是编出一个听着合理、现实中不存在的结构。以下均为两轮实调研的判定结果：

| 看着像什么 | 实际是什么 | 案例 |
|---|---|---|
| 追问链条 | **设问并列式**——设问只是开篇装置，主体是并列板块，不构成追问链条 | 《什么是武汉》（星球研究所，2019） |
| 双线对照 | **板块并列式**——一个板块独占一城，不是同场对照 | 秦朔《新双城记：无锡和宁波》（2019） |
| 追问链条 | **论点驱动的评论**——无历程追溯 | 《看到哈尔滨的经济数据，天水还怎么照抄作业？》（冰川思享号，2024） |
| 深度叙事 | **清单式公文**——不是叙事文 | 政府调研报告体（如泰州学淄博"3 看点 3 思考 3 经验"） |
| 城市深度文 | **商业软文**——商业收口 | 兽楼处《郑州不再沉默》 |

**「先彼后己式」（1/3 外地完整故事 + 2/3 本地）：两轮案例调研零命中。** 外地热点在真实生态中只有两种处理——压缩成短引子，或拆散为论据。**该结构不得作为独立结构推荐或采用。**

## 三、喂养规则

**分工**：用户提名 → agent 实读全文、拆结构、定坐标、判门槛 → 报给用户 → 用户裁决 → 入库。**实读那步必须做**，不读全文不得入库。

**入库门槛**：①落得进某个坐标；②拆得出一句话结构骨架；③已实读全文，非凭摘要判断。

**容量**：每个坐标最多 2 篇（1 正 1 次）。满了只能替换，说明替换理由。全库上限约 1,000 tokens。

**结构幻觉清单**只增不删——每抓到一个"看着像 X 实为 Y"的案例就追加一行，这部分不受容量限制。

**禁止**：不得自创坐标或分类。坐标随 ⑧ 第一步·一 变动，本库跟随，不反向定义。
